# gap-moe-survey-v5

GitHub Pages上で動作する、ギャップ萌え認知アンケートのv5モックです。

## v5で変更したアンケート構造

各キャラクターについて3種類の服装変換画像を、条件名を隠して A / B / C として提示します。

1. **全体評価**
   - 同一人物性
   - 元印象からの変化
   - ギャップ
   - 萌え
   - ギャップ萌え
   - 似合い度
   - 違和感
2. **要素別評価**
   - まず変化を感じた要素を選択
   - 選択した要素のみ、ギャップ萌えへの関係を5段階評価
3. **3画像比較**
   - ギャップ萌え順
   - 最もギャップを感じる画像
   - 最も萌えを感じる画像
   - 「どれもギャップ萌えしない」選択肢

全体評価を確定するまで要素別質問を見せないため、要素名による第一印象へのプライミングを抑えています。

## ファイル

- `index.html` : 画面構造
- `style.css` : レスポンシブUI
- `survey.js` : 質問、ランダム化、回答保存、送信処理
- `images/` : v4に含まれていたモック画像

## モック画像について

現在は画面確認用として、各キャラクターの A / B / C に同一画像を割り当てています。本調査では `survey.js` の `characters[].variants[]` を実際の変換画像へ差し替えてください。

回答者には `soft / medium / strong` の内部条件名を表示しません。表示順は回答者ごとにランダム化されます。

## Google Apps Script

`survey.js` 冒頭の `GAS_URL` に既存URLを保持しています。v5では回答JSONの構造が変わったため、受信側スクリプトも新しいスキーマに合わせて更新してください。

空文字にすると外部送信を行わず、回答を `localStorage` に保存します。完了画面からJSONをダウンロードできます。

## GitHub Pagesでの利用

このディレクトリの内容をリポジトリ直下へ配置し、GitHub Pagesを有効化してください。ビルド処理や外部ライブラリは不要です。
